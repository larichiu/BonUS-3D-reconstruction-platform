# Rights and attribution

This package prepares the user's existing reconstruction source and LCedit variants for repository publication. It does not change ownership or assert a license on behalf of other contributors. No open-source license has been chosen. The repository owner should establish contributor rights and choose a code license and an explicit sample-data license before inviting reuse under stated terms.

The example is derived from the user's existing sawbone annotation workflow. There is no new grant of redistribution or research-use rights beyond any rights the owner already holds. Third-party dependencies retain their own licenses. Python, Streamlit, Plotly, NumPy, pandas, openpyxl and Pillow are installed from their packages rather than copied into this repository.

Original source hashes are recorded in `docs/source_hashes.json` to identify the snapshots used for this preparation. Release files include deliberate portability, upload and documentation changes; their bytes therefore differ from the original source hashes. No historical Git history or authorship dates have been fabricated.
