# original

Launch from the repository root: `python launch.py --variant original`. See [root README](../../README.md).

Baseline reconstruction, calibrated probe path, image-plane overlay, combined scans, and CSV/PLY export. The current UI uses a cropped top-left image origin and provisional X=45°, Y=-90°, Z=0° orientation. The older source README described an earlier top-centre convention; it is superseded here.
